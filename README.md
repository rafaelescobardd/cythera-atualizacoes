# Cythera: versões

O Cythera é um programa para criar e organizar o seu mundo: fichas, o livro, o mural, a linha do tempo, a árvore genealógica, os mapas, as línguas inventadas e as fichas de RPG. Tudo fica em pastas no seu computador.

**As versões para baixar estão em [Releases](https://github.com/rafaelescobardd/cythera-atualizacoes/releases).** O programa também avisa sozinho quando há versão nova.

Este repositório guarda só os instaladores e as notas de cada versão.
